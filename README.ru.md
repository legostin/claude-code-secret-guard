# secret-guard: секреты не попадут в контекст Claude Code

[English version](README.md) · [Сайт](https://legostin.github.io/claude-code-secret-guard/)

**secret-guard** — мод для [Claude Code](https://claude.com/claude-code) (плагин функциональных хуков). Он не пускает к модели API-ключи, токены, пароли и приватные ключи. Каждый вывод инструмента, промпт и вложение проверяются [gitleaks](https://github.com/gitleaks/gitleaks) **до того**, как их прочитает модель. Если найден секрет, агент встаёт на паузу, и решение за вами: вырезать секрет, скрыть весь вывод или пропустить.

```
Bash: cat .env: найдены секреты (github-pat ghp_…[40]). Что отдать модели?
  1. Вырезать секреты
  2. Скрыть весь вывод
  3. Пропустить к модели
  4. Не секрет, пропускать
```

Модель увидит `GITHUB_TOKEN=[SECRET:github-pat#1]`, а само значение так и не узнает.

## Зачем

Агент читает всё, что перед ним: `cat .env`, конфиги, `curl -v` с заголовком `Authorization`, логи, стектрейсы. Всё прочитанное уходит модели и остаётся в транскрипте сессии. Если секрет хоть раз попал в разговор, он там навсегда.

secret-guard ставит проверку между вашей машиной и моделью:

- **До того, как модель что-то прочитает.** Мод перехватывает места, через которые текст входит в контекст, а не чистит транскрипт задним числом. Вырезать секрет из истории после отправки бесполезно: модель его уже видела.
- **Значение не покидает машину.** В диалогах, панели и журнале только маска (`ghp_…[40]`) и хэш. Само значение есть лишь в памяти мода, пока проверяется текст.
- **В сомнительных случаях скрывает.** Закрытый диалог, сбой сканера или упавший хук означают «скрыть». Молча ничего не проходит.

## Что проверяется

| Откуда текст попадает в контекст | Хук | При находке |
|---|---|---|
| Вывод любого инструмента: Bash, Read, Grep, WebFetch, MCP, субагенты | `tool.call` | Диалог: вырезать / скрыть весь вывод / пропустить / не секрет |
| Ваш промпт (вставили ключ) | `prompt.submit` | Диалог: вырезать / отправить как есть / не отправлять (текст вернётся в поле ввода) |
| Файл через `@path` | `prompt.mention` | Диалог: вырезать / не прикладывать / приложить как есть |
| CLAUDE.md, напоминания, вложения | `prompt.context`, `prompt.attachment` | Вырезается автоматически, запись в журнале |
| Любая другая строка разговора | `session.append` | Страховка: вырезается автоматически |

gitleaks сам декодирует base64, hex и percent-encoding (до 5 уровней), так что `cat .env | base64` тоже ловится. Строка с закодированным секретом скрывается целиком.

Секрет, который вы уже раз вырезали, дальше вырезается без вопросов. Спрашивать снова будут только о **новых** секретах.

## Установка

Понадобятся:

- **Claude Code** с поддержкой модов (функциональных хуков). Проверено на версии 2.1.292.
- **gitleaks** 8.19 или новее:
  ```sh
  brew install gitleaks
  ```

Затем в Claude Code:

```
/plugin install secret-guard --marketplace legostin/claude-code-secret-guard
```

Ответьте `y` на вопрос о добавлении маркетплейса и выберите область установки (user scope защищает все проекты). Хуки начинают работать сразу.

## Использование

- **`/secrets`** открывает боковую панель. В ней статус сканера и журнал находок: маска, источник, ваше решение. Там же allowlist: ложное срабатывание можно отметить кнопкой «не секрет» или убрать запись из списка.
- **Статус-строка** показывает `secret-guard: скрыто N · /secrets`, если что-то было скрыто. Если gitleaks не найден, в ней будет команда установки.
- **Язык.** Диалоги и панель говорят по-английски или по-русски. Русский включается командой `/plugin configure secret-guard@secret-guard` или в `settings.json`:
  ```json
  { "pluginConfigs": { "secret-guard@secret-guard": { "options": { "language": "ru" } } } }
  ```
  Модель всегда читает английский.
- **Правила проекта.** gitleaks подхватывает `.gitleaks.toml`, `.gitleaksignore` и комментарии `gitleaks:allow` из корня проекта сессии.

## Гарантии и ограничения

Проверено (см. [`tests/`](tests) и живые прогоны в [`docs/design.md`](docs/design.md)):

- Вырезанного или скрытого секрета нет ни в запросе к модели, ни в файле транскрипта сессии. Переписываются и результат инструмента для модели, и запись для экрана в транскрипте.
- Закрытый диалог означает «скрыть». В headless-режиме (`claude -p`) показать диалог некому, поэтому всё найденное скрывается.
- Если gitleaks недоступен, мод спрашивает вас. Там, где спросить нельзя, текст скрывается.

Чего мод не делает:

- **Это сканер по шаблонам.** Он находит то же, что правила и энтропийные проверки gitleaks (около 200 типов). Пароль без характерной формы или секрет, разбитый на несколько выводов, может пройти.
- **Картинки и скриншоты не проверяются.**
- **«Пропустить к модели» значит пропустить.** Пропущенное значение модель знает.
- Терминал может на мгновение **нарисовать** исходный вывод до перезаписи. Это видно только на вашем экране: модель и транскрипт эту форму не получают.
- Если мод не загружен (отключён или установка сломана), защиты нет. Проверяйте статус-строку или `/secrets`.
- Моды — API Claude Code в раннем доступе, он может меняться между релизами.
